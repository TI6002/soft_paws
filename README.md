# Приют «Тёплые Лапки» — HTML5/CSS3/JS проект

## Структура проекта
```
shelter-project/
├── index.html          ← вся страница (одна страница, как требуется в задании)
├── css/
│   └── style.css       ← все стили
├── js/
│   └── script.js        ← вся логика (меню, фильтр, счётчики, форма)
└── images/
    └── shelter-team.jpg ← локальное изображение-заглушка (замените на своё)
```

## Как открыть в VS Code
1. Распакуйте архив в удобную папку.
2. В VS Code: **File → Open Folder…** → выберите папку `shelter-project`.
3. Поставьте расширение **Live Server** (Ritwick Dey) и нажмите
   «Go Live» внизу справа — либо просто откройте `index.html`
   двойным кликом в браузере.

## Как вставить свои фотографии
1. Найдите папку `images/`.
2. Скопируйте туда свои файлы, например `moya-sobaka.jpg`.
3. В `index.html` замените `src="images/shelter-team.jpg"` на
   `src="images/moya-sobaka.jpg"` (и то же самое для фото питомцев —
   сейчас там временные картинки с `picsum.photos`, просто замените
   `src="https://picsum.photos/..."` на `src="images/имя-файла.jpg"`).
4. Обязательно меняйте и атрибут `alt="…"` — опишите словами, что на фото,
   это требование доступности и валидации HTML5.

## Что обязательно нужно поменять перед сдачей
- В самом низу страницы (подвал / `<footer>`) впишите **своё настоящее
  имя** и **свой студенческий ID** вместо примера
  «Иванова Анна Сергеевна» / «20263145».
- При желании поменяйте адрес, телефон и название приюта на свои — это
  никак не сломает разметку.

## Проверка на validator.w3.org
1. Откройте <https://validator.w3.org/#validate_by_upload>.
2. Загрузите файл `index.html`.
3. Если валидатор покажет предупреждение про `loading="lazy"` на
   старых профилях проверки — выберите профиль **HTML5** (он уже
   должен стоять по умолчанию), тогда предупреждений быть не должно.
4. Все теги в файле закрыты, атрибуты в нижнем регистре, устаревших
   элементов (`<font>`, `<center>`, `border=` и т.п.) не используется —
   так что страница должна пройти проверку без ошибок «из коробки».
   Если после ваших правок валидатор что-то подсветит — это будет
   конкретная строка, которую легко поправить.

## Что уже реализовано по заданию

**Обязательная часть**
- 1 главный заголовок `<h1>`, заголовки двух уровней `<h2>`/`<h3>`
- 4+ параграфов текста
- 5 разных элементов форматирования текста: `<strong>`, `<em>`,
  `<mark>`, `<small>`, `<abbr>`
- Списки: `<ul>`, `<ol>`, `<dl>`, и вложенный список внутри `<li>`
- Спецсимволы через HTML-сущности: `&mdash;`, `&ndash;`, `&laquo;`/`&raquo;`,
  `&copy;`
- Ссылка на внешний сайт, внутренняя ссылка на другую часть страницы
  (меню и «Вернуться наверх»), ещё одна содержательная ссылка,
  которая всегда открывается в новой вкладке (`target="_blank"`)
- Картинка из локальной папки, картинка из интернета, картинка-ссылка
- Видео с YouTube
- Информация об авторе (ФИО и студенческий ID) в подвале страницы
- Кодировка UTF-8, без устаревших тегов и атрибутов

**Дополнительная часть (Task II)**
- Таблица с объединёнными ячейками (`rowspan`/`colspan`)
- Семантические блоки HTML5: `<header>`, `<nav>`, `<main>`,
  `<section>`, `<article>`, `<aside>`, `<footer>`
- Форма (заявка волонтёра) с разными типами полей
- CSS-стилизация (отдельный файл, адаптивная вёрстка)
- JavaScript: мобильное меню, фильтр карточек питомцев,
  анимированные счётчики, проверка формы

Форма и логика волонтёрской заявки добавлены не «для галочки», а
потому что для настоящего сайта приюта это самая логичная функция —
полезнее, чем регистрация/логин, которые в реальном приюте обычно
не нужны обычным посетителям сайта.
